## [비호환] Holiday — nextBusinessDay → addBusinessDays, substituteYn → substitute(boolean)

- HolidayService의 nextBusinessDay가 addBusinessDays로 바뀌었습니다. (영업일 N일 추가 가능)
- GET /api/holidays 응답의 substituteYn 필드가 substitute(boolean)로 바뀌었습니다.
- HolidayVO의 substituteYn(String) 필드가 substitute(boolean)로 바뀌었습니다.

변경 전
```java
LocalDate nextBusinessDay(LocalDate date)
```
변경 후
```java
LocalDate addBusinessDays(LocalDate date, int days)
```

**영향 받는 API·메서드**: GET /api/holidays, GET /api/holidays/next-business-day, addBusinessDays, getHolidays
**할 일**: nextBusinessDay를 호출하는 코드는 addBusinessDays로 바꾸세요 (다음 영업일은 addBusinessDays(date, 1)). substituteYn을 읽는 코드는 substitute(boolean)로 바꾸세요. 예: `holidayService.addBusinessDays(date, 1)`, `holiday.isSubstitute()`
**영향 프로젝트**: shop-app 2곳, admin-app 1곳

> 설명 메모: 공휴일 목록 응답 필드와 서비스 메서드 시그니처가 바뀌어, 기존 API를 쓰는 코드는 컴파일 오류나 응답 오독이 발생합니다. 영향 받는 프로젝트 담당자에게는 개별 알림이 갔습니다.

## [신규] Code — 공통코드 조회 API

- 화면의 선택 박스 목록이나 상태값 표시 이름을 공통코드에서 가져올 때 사용합니다.
- 코드 목록은 캐시되므로, 코드가 바뀌어도 캐시 해제·서버 재시작 전까지 반영되지 않습니다.
- getCodeName은 코드를 찾지 못하면(없거나 사용하지 않는 코드) 코드값을 그대로 반환합니다.

사용 예
```java
GET /api/codes/GENDER
→ { "success": true, "data": [ { "code": "M", "codeName": "남", "sortOrder": 1 }, { "code": "F", "codeName": "여", "sortOrder": 2 } ] }

List<CodeVO> codes = codeService.getCodes("GENDER");
String name = codeService.getCodeName("GENDER", "M");
```

**API**: GET /api/codes/{groupCode}, GET /api/codes/{groupCode}/{code}/name
**함께 쓰는 자산**: ApiResponse

> 설명 메모: 공통코드 목록과 표시 이름을 조회하는 신규 API입니다. 선택 박스 옵션이나 상태값 표시 이름에 활용할 수 있습니다.

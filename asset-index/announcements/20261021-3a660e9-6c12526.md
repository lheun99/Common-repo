## [동작 변경] Toast — info·success 토스트 자동 닫기 시간 3초 → 5초

- info·success 토스트의 자동 닫기 시간이 3초에서 5초로 바뀌었습니다.
- error 토스트는 기존과 같이 자동으로 닫히지 않습니다.

변경 전
```
3초 (3000ms)
```
변경 후
```
5초 (5000ms)
```

**할 일**: 수정 불필요. info·success 토스트가 5초 동안 표시된다는 점만 확인하세요.

> 발표 메모: info·success 토스트가 5초 동안 표시됩니다. 수정은 필요 없으며, 표시 시간만 길어졌습니다.

---

## [신규] Toast — 화면 오른쪽 위에 토스트 알림을 표시하는 영역

- 이런 때 쓰세요:
  - 저장·삭제 결과 같은 짧은 알림을 띄울 때
  - info·success 토스트는 5초 뒤 자동으로 닫히고, error 토스트는 자동으로 닫히지 않는다.
  - 토스트는 최대 3개까지 표시되며, 넘치면 가장 오래된 토스트부터 사라진다.

사용 예
```tsx
// 앱 최상위
<ToastContainer />

// 화면에서
const toast = useToast();
toast.success("저장되었습니다.");
```

**대체할 수 있는 곳**: shop-app 1곳 (브라우저 alert() 사용)

> 발표 메모: 토스트 알림 기능이 새로 추가되었습니다. 브라우저 alert() 대신 사용할 수 있습니다.

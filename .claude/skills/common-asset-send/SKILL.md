# 개발자별 알림 메시지 발송 (Slack 테스트용)

`common-asset-dispatch`가 저장한 메시지 초안을 **그대로** Slack 다이렉트 메시지로 보낸다.

- 메시지 내용을 만들거나 고치지 않는다. 초안의 `text`를 그대로 보낸다.
- 보내는 일은 `tools/send_slack.py`가 한다. 이 스킬은 대상 확인, 사용자 승인, 실행, 결과 기록을 맡는다.
- 이 단계는 PMS 쪽지 연동 전의 테스트용이다. 나중에 PMS 쪽지 API가 열리면 보내는 부분만 바꾼다.

## 경로

- 입력: `common-repo/asset-index/messages/<이름>.json` (기본은 `status`가 `draft` 또는 `partial`. 재전송 요청이면 `sent`도 대상이다.)
- 수신자 매핑: `common-repo/asset-index/slack-users.json` (이름 → Slack 멤버 ID)
- 토큰: 환경변수 `SLACK_BOT_TOKEN` 또는 `common-repo/.slack-token`. 토큰 값은 읽거나 출력하지 않는다.
- 스크립트: `common-repo/tools/send_slack.py`

## 핵심 원칙

1. **토큰을 보지 않는다.** 파일을 열거나 출력하지 않고, 메시지 본문이나 커밋에도 넣지 않는다. 없으면 설정 방법만 안내한다.
2. **보내기 전에 반드시 승인을 받는다.** Slack으로 나간 메시지는 되돌릴 수 없다.
3. **매핑에 없는 수신자는 보내지 않는다.** 건너뛰고 결과에 알린다. 지어내지 않는다.
4. **이미 보낸 메시지(`sentAt`이 있는 것)는 기본으로 다시 보내지 않는다.** 단, 요청에 "다시", "재전송"이 있으면 `--resend`로 다시 보낸다. (미리보기에서 "다시 보낼 예정"으로 구분해 알린다.)
5. **셸 명령은 한 번에 하나만 실행한다.** `;`, `&&`로 잇지 않는다.

## 순서

### 1. 보낼 메시지 파일 고르기
- `asset-index/messages/*.json`에서 `status`가 `draft` 또는 `partial`인 파일을 찾는다. 재전송 요청이면 `sent`인 파일도 포함한다.
- 요청에 문서 이름이나 해시가 있으면 그 파일만 쓴다.
- **자산 이름**(예: Dept, Pagination)이 있으면 각 파일의 `messages[].assets[].asset`(전체 공지는 `broadcasts[].asset`)에서 그 자산이 들어 있는 파일만 대상으로 한다. 여럿이면 모두 보여 주고 고르게 한다.
- 이름이 하나도 없으면 대상 파일을 모두 보여 주고 어느 것을 보낼지 묻는다.
- 대상이 없으면 "보낼 메시지가 없습니다"라고 알리고 끝낸다.

### 1-2. 받는 사람 지정
요청에 받는 사람 이름이 있으면(예: "김개발한테 Dept 알림 보내줘", "김개발, 이개발에게만") 그 이름들을 `--to 김개발,이개발`로 미리보기와 전송 명령에 붙인다. 없으면 `--to`를 쓰지 않고 파일의 수신자 전원이 대상이다. 지정한 이름이 파일에 없으면 스크립트가 알리므로 결과에 그대로 전한다.

### 2. 미리보기
`python tools/send_slack.py <메시지 파일> --dry-run`을 실행하고, 결과를 표로 보여 준다. 재전송 요청이면 `--resend`, 받는 사람을 지정했으면 `--to`를 함께 붙인다.
- 보낼 예정 / 다시 보낼 예정: 수신자, Slack 계정, 메시지 첫 줄
- 건너뜀: 매핑 없는 수신자, 받는 곳이 미정인 전체 공지
- 질문 도구로 **"이대로 Slack으로 보낼까요?"** 한 줄만 묻는다. 거절하면 아무것도 보내지 않는다.

### 3. 전송
`python tools/send_slack.py <메시지 파일>`을 실행한다. 재전송이면 `--resend`, 받는 사람을 지정했으면 `--to`를 붙인다. (미리보기와 같은 옵션으로 실행한다.)
- 토큰 오류가 나면 `.slack-token` 파일 또는 `SLACK_BOT_TOKEN` 설정을 안내하고 끝낸다.
- 성공한 메시지에는 `sentAt`, `slackTs`가 기록되고, 파일의 `status`가 바뀐다. (전부 보냈으면 `sent`, 일부만 보냈으면 `partial`)

### 4. 기록 커밋
메시지 파일만 커밋한다.
```
git -C common-repo add <메시지 파일>   # 파일 이름에 공백·괄호가 있으므로 경로는 따옴표로 감싼다
git -C common-repo commit -m "docs: 알림 발송 기록 (<파일 이름>)" -m "- Slack 전송 <N>건, 건너뜀 <S>건, 실패 <F>건" -- <메시지 파일>
```
push는 묻고 진행한다.

### 5. 결과 보고
- 전송한 수신자와 건수, 건너뛴 수신자와 이유, 실패한 수신자와 오류 코드
- 건너뛴 전체 공지는 "받는 곳이 정해지지 않아 보내지 않았습니다"라고 적는다.
